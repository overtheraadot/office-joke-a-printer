## The entry

> The office printer only ever jams on the document you actually need — it's read them all, and some secrets are safer jammed inside it.

134 characters, 25 words, 1 line. The premise: the office printer is an oracle that only speaks in paper jams. It has read every document that ever passed through it, so it knows everyone's secrets — and it jams precisely when the important document is due, because some secrets are safer jammed inside it. The punchline's word "jammed" closes the loop on the jam itself.
